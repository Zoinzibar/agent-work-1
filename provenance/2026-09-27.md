Two things worth writing down:

- **The Hub does not 404 anonymously.** A repo that does not exist (or is
  private) gets **HTTP 401** with the body above; a tokened request gets a
  404. The first version of the checklist said "a 404 is the expected result".
  That step could not pass without a token. The script now classifies that
  401 body as `missing (or private)` and reads `HF_TOKEN` if set.
- `https://hermes-agent.nousresearch.com/docs/llms.txt` was fetched again and
  still responds with the docs index (same top-level structure as the first
  pass). Still no WARC, still no body hash.
